Resumo
A apresentação abordou o uso de ferramentas de automação e análise de dados via Cloud Code.

Estratégias de análise dados
A engenharia de dados prioriza a facilitação de acesso via protocolos de contexto e interfaces de linha de comando. Ferramentas locais garantem controle e eficiência superior de tokens.

Segurança e automação técnica
A implementação de guard rails impede comandos destrutivos e garante fluxos de trabalho seguros. O uso de navegadores agênticos permite realizar auditorias e planos de mensuração automáticos.

Implementação do Analytics Copilot
A solução centraliza conexões com fontes de dados e simplifica a exploração analítica conversacional. Esta ferramenta otimiza o fluxo de trabalho ao reduzir a dependência de desenvolvedores.

Detalhes
* Introdução e Contexto: Lucian Fialho deu início à apresentação, estabelecendo o objetivo do bate-papo: explorar o uso do Cloud Code para análise de dados, focando em conceitos práticos e estratégias de implementação, com a participação de diversos membros da comunidade (00:05:23) (00:14:44).
* Stack de Ferramentas e IA: Durante o aquecimento, discutiu-se a eficácia do stack de ferramentas do Google (Google Analytics, Google Search Console, Google Ads, Google Tag Manager) aliado ao uso de IA e ferramentas como o Antigravity, destacando o valor agregado para empresas que utilizam esse ecossistema (00:12:07) (00:18:10).
* Desafios da Preparação de Dados: Lucian Fialho ressaltou a importância dos "seis pilares de confiança em dados", enfatizando que o tempo dedicado à preparação dos dados para garantir qualidade, consistência e completude é significativamente maior do que o tempo de tomada de decisão, reforçando que a IA pode atuar como uma aliada crucial nessa etapa (00:15:43).
* O Papel da Engenharia de Dados: Discutiu-se a mudança na função dos engenheiros de dados, que devem evoluir de "gatekeepers" (responsáveis por entregar relatórios manualmente) para "enablers" (facilitadores), fornecendo acesso seguro às bases de dados via integrações como MCP (Model Context Protocol) ou APIs, permitindo que analistas consumam informações de forma autônoma (00:20:51) (00:24:31).
* Model Context Protocol (MCP): Foi introduzido o conceito de MCP como uma camada fundamental para conectar a IA às fontes de dados de forma segura, permitindo que a IA interaja com as bases de dados da empresa sem que o usuário precise acessar diretamente as estruturas complexas de um data warehouse (00:23:26).
* Cloud Code vs. Ferramentas Web: Lucian Fialho comparou o Cloud Code com interfaces web como o ChatGPT, destacando que o Cloud Code, através da versão desktop e do uso de CLI (Command Line Interface), oferece maior controle, segurança e capacidade de integrar recursos locais da máquina, ao contrário do fluxo manual de copiar e colar na web (00:28:01).
* Eficiência de Tokens e Performance: Debatou-se a diferença de custo em consumo de tokens entre o uso de MCP e o uso de CLI, sendo este último frequentemente mais eficiente, o que levou à criação de bibliotecas próprias pela equipe da Métricas Boys para otimizar o processo (00:31:43) (00:35:10).
* GMP CLI e DuckDB: Apresentou-se o GMP CLI (Google Marketing Platform CLI), desenvolvido pela Métricas Boys para conectar ferramentas como GA4, BigQuery e Google Ads, e a implementação do banco de dados DuckDB como uma camada de cache local, permitindo que consultas frequentes sejam feitas sem a necessidade de atingir repetidamente a API ou o data warehouse (00:32:53) (00:41:16).
* Técnicas Técnicas Avançadas: Foram explicadas técnicas como o "Disclosure CLI", que habilita a IA a aprender e navegar via comandos de terminal, e o uso do Spectral CLI, que permite a conexão a qualquer API desde que haja uma documentação em Swagger, facilitando a automação de integrações (00:37:05) (00:42:08).
* Benchmarks de Desempenho: Lucian Fialho compartilhou benchmarks internos realizados pela equipe, comparando o MCP do Google Analytics com o GMP CLI desenvolvido por eles, demonstrando que o uso do CLI foi mais performático e consumiu menos tokens em uma série de tarefas de análise (00:39:15).
* Recursos do Cloud Code Desktop: Destacaram-se funcionalidades específicas do Cloud Code Desktop, como a capacidade de rodar plugins, configurar a inicialização com comandos de segurança (evitando confirmações manuais constantes com comandos como "danger skip permission") e o recurso de controle remoto, que permite gerenciar a máquina pelo celular (00:46:25) (00:51:11).
* Estrutura de Skills e Hooks: As "Skills" foram definidas como receitas em Markdown contendo ingredientes (fontes de dados) e modo de preparo (sequência de passos), enquanto os "Hooks" foram descritos como scripts de segurança essenciais para manter o uso determinístico e seguro das ferramentas (00:48:36) (00:53:13).
* Padronização com Skill Creator: Enfatizou-se a importância de não apenas copiar Skills de terceiros, mas adaptá-las ao contexto de trabalho, utilizando a ferramenta "Skill Creator" para automatizar a criação dessas Skills e garantir que todo o time siga uma metodologia padronizada na análise de dados (00:57:31) (01:00:53).
* Segurança e Guard Rails no Cloud Code: Lucian Fialho explica a importância de implementar "guard rails" ou "hooks" de segurança no Cloud Code para impedir que usuários executem comandos destrutivos acidentais, como a exclusão de artigos ou tabelas. Eles detalham que eventos específicos, como "session start", "user prompt submit" e "PR to use", permitem analisar e bloquear ações antes que sejam executadas. Lucian Fialho disponibilizou uma série de scripts prontos, incluindo bloqueios para comandos como "rm -rf" e "drop table", para que os usuários possam integrar camadas de segurança em seus fluxos de trabalho (01:05:13).
* Uso do GitHub para Colaboração: Lucian Fialho enfatiza que profissionais, inclusive de áreas como marketing, precisam desenvolver competências técnicas, como o conhecimento básico de GitHub. Eles argumentam que, embora não seja necessário ser um especialista em programação, entender o funcionamento do Git e do GitHub é essencial para acessar, copiar e compartilhar scripts e "skills" que aumentam a produtividade e a segurança dentro das equipes (01:08:40).
* Capacidades de Navegação (Agent Browser): Lucian Fialho aborda a funcionalidade de permitir que o Cloud navegue em navegadores para realizar auditorias, testes de jornada e extração de informações. Eles observam que, embora essa prática consuma mais tokens, é um recurso fundamental para detectar problemas como a perda de "client ID" em fluxos de e-commerce. Para gerenciar recursos computacionais e consumo de tokens, Lucian Fialho recomenda o uso da extensão "Agent Browser" para Chrome em vez de uma instância completa do navegador (01:10:46).
* Planos de Mensuração e Auditoria com GTM: Lucian Fialho explica que a navegação agêntica permite que o Cloud auxilie na criação de planos de mensuração ao simular a navegação do usuário em um site. Essa capacidade facilita a auditoria de tags no Google Tag Manager (GTM), permitindo identificar erros em acionadores e garantir o disparo correto de eventos em plataformas como Google Analytics, Google Search Console, Google Big Query e Google Ads (01:15:11).
* Análise de CRO com Heurísticas: Lucian Fialho destaca a aplicação de Cloud para Conversion Rate Optimization (CRO), utilizando a capacidade de navegação da IA para realizar auditorias baseadas em heurísticas, como as de Nielsen. O processo envolve navegar pelo site, capturar prints e identificar elementos como "hero sections" e CTAs, servindo como uma etapa inicial para antecipar problemas antes da execução de experimentos (01:17:21).
* Automação com Loop e Schedule: Lucian Fialho apresenta os recursos de "loop" e "schedule" disponíveis no Cloud Desktop e Cloud Code para automação de tarefas. Esses recursos permitem que os usuários agendem a execução de pipelines ou verificações recorrentes, como checagens de hora em hora ou disparos automáticos, reduzindo o esforço manual em processos contínuos de análise e extração de dados (01:20:52).
* Qualidade de Dados e Independência Técnica: Lucian Fialho ressalta que as estruturas de "skills" apresentadas podem ser aplicadas para assegurar a qualidade de dados (data quality), como a extração de informações de um data warehouse ou a análise de logs do Google Cloud Watch. Eles incentivam a adoção dessas práticas técnicas, afirmando que isso torna os profissionais mais independentes e produtivos em suas funções (01:22:00).
* Introdução ao Analytics Copilot: Lucian Fialho apresenta a ferramenta "Analytics Copilot", desenvolvida pela Métricas Boss para simplificar a conexão de fontes de dados e a interação com IA. A ferramenta resolve a complexidade técnica de montar camadas de "cache" e conexões manuais, oferecendo uma interface desktop para explorar dados conectando-se a diversos provedores de IA e mais de 100 fontes de dados, como Google Analytics 4, Meta Ads, Vertex AI, Shopify e Snowflake (01:23:59).
* Recursos e Gestão de Skills no Analytics Copilot: Lucian Fialho detalha funcionalidades do Analytics Copilot, como o monitoramento automático de catálogos do Facebook e Google Merchant Center, a gestão de credenciais múltiplas por workspace e o compartilhamento de "skills" entre membros da equipe. A ferramenta inclui habilidades pré-configuradas para auditorias de LGPD e outras demandas de análise, permitindo a colaboração eficiente dentro de empresas (01:30:22).
* Usabilidade e Geração de Relatórios: Lucian Fialho explica que o Analytics Copilot mantém uma interface de chat conversacional para exploração de dados, similar ao Cloud, mas com acesso mais direto e economia de tokens. Eles citam o exemplo de usuários na Ering que automatizaram a criação e distribuição de relatórios diários ou semanais, tornando a análise de dados mais frequente e acessível para o time (01:32:48).
* Estudo de Caso de CRO e Testes A/B: Lucian Fialho compartilha um estudo de caso onde o Analytics Copilot foi utilizado para identificar e solucionar uma fricção na jornada de compra de uma marca de óculos. O processo envolveu a criação de uma funcionalidade de detecção de formato de rosto via HTML/JavaScript, que reduziu a dependência de desenvolvedores e agilizou a implementação de testes A/B, otimizando o pipeline de trabalho (01:35:05).
* Workshop Presencial e Encerramento: Lucian Fialho anuncia um workshop presencial de CRO marcado para o dia 10 de setembro em São Paulo, focado em práticas de conexão e configuração utilizando Cloud e Copilot.
