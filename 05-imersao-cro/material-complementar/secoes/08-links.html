Conectar o GA4 — o passo a passo por trás do "conecta pra mim"

No workshop você colou a URL e pediu. Por trás, o Claude faz isto. Se travar em algum passo, é aqui que você confere.

  1. Pré-requisitos: Python 3.10 ou mais novo, pipx, e a CLI gcloud do Google Cloud instalados.
  2. Um projeto no Google Cloud (console.cloud.google.com) com duas APIs ativadas: Google Analytics Admin API e Google Analytics Data API.
  3. Login, com a conta que enxerga o GA4:
gcloud auth application-default login \
  --scopes https://www.googleapis.com/auth/analytics.readonly,https://www.googleapis.com/auth/cloud-platform

Ao terminar, o gcloud mostra o caminho de um arquivo de credenciais. Guarde.

  1. Registrar no Claude Code, trocando os dois valores em maiúsculas:
claude mcp add analytics-mcp --scope user \
  -e "GOOGLE_APPLICATION_CREDENTIALS=CAMINHO_DO_ARQUIVO_DE_CREDENCIAIS" \
  -e "GOOGLE_PROJECT_ID=ID_DO_SEU_PROJETO" \
  -- pipx run analytics-mcp

Sessão nova, e pergunte: "quais propriedades do GA4 você enxerga?". Se ele listar, está conectado. Fonte: README oficial em github.com/googleanalytics/google-analytics-mcp.
