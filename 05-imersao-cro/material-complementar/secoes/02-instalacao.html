Instalação passo a passo

Mac e Windows. Sem Node, sem npm.

Passo 1 — instalar o Claude Code

Abra o terminal (no Mac: Cmd + Espaço, digite Terminal, Enter. No Windows: tecla Windows, digite PowerShell, Enter) e cole a linha do seu sistema.

mac · Terminal

curl -fsSL https://claude.ai/install.sh | bash

windows · PowerShell

irm https://claude.ai/install.ps1 | iex

Passo 2 — abrir e entrar

claude

Esse comando abre o login no navegador. Use a mesma conta Claude Pro do bloco da manhã. Se o navegador não abrir sozinho, copie a URL que apareceu no terminal e cole no navegador.

Passo 3 — o kit do curso, seis linhas

Uma pasta para a loja, e o kit dentro do Claude. Rode fora do Claude Code — se você estiver dentro dele, digite /exit antes. Tudo que roda com /cro: na frente vem daqui.

terminal · mac e windows · fora do claude

mkdir minha-loja
cd minha-loja
claude plugin marketplace add lucianfialho/cro-plugin
claude plugin install cro@cro-plugin
claude plugin marketplace add anthropics/claude-plugins-official
claude plugin install skill-creator@claude-plugins-official

Seis linhas, uma vez na vida. O esperado é uma mensagem com ✔ em cada uma das quatro linhas de plugin. Para conferir depois:

claude plugin list
claude plugin details cro@cro-plugin   # deve mostrar Skills (10)

Quando der errado

O que aparece na telaO que fazer
command not found: claude (mac), ou uma frase com claude e "não é reconhecido" (win) O instalador terminou, mas o terminal que está aberto não sabe disso. Feche a janela do terminal e abra de novo. Fechar é clicar no X (ou Cmd+Q no Mac) — minimizar não conta.
O Windows bloqueia o script — uma frase com "execution of scripts is disabled" ou ExecutionPolicy Feche o PowerShell, clique com o botão direito no ícone dele e escolha Executar como administrador. Rode Set-ExecutionPolicy RemoteSigned, confirme com S (ou Y) e rode a linha de instalação de novo.
O plugin não aparece: você digita / e não vê /cro: na lista, mesmo tendo visto a mensagem de sucesso Plugin só entra na próxima abertura. Saia e entre de novo: digite /exit, espere o cursor do terminal voltar, digite claude e confira de novo.
Você digitou um comando claude plugin ... e o Claude respondeu em texto, explicando o comando Você está dentro do Claude Code, e ali aquilo não é comando, é pergunta para o modelo. Nada foi instalado. /exit e rode de novo no terminal.
Uma frase com "Failed to clone marketplace repository" Falta o git nessa máquina. Faça este passo em dupla com alguém que tenha, e instale o git depois, em casa.
Nenhuma linha acima bate com o que você está vendo Não insista sozinho. Chame o facilitador e mostre a tela.

Regra geral das três saídas: comando não encontrado → feche e abra o terminal. Windows reclamando de script → PowerShell como administrador. Plugin invisível → saia e entre no Claude de novo. Quase tudo cai numa dessas.
